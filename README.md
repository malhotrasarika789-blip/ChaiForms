# ChaiForms 🚀

A full-stack form builder SaaS application where users can create custom forms, share them, and collect responses.

## 🌐 Live Demo

Frontend:
https://chaiforms-app.vercel.app/

Backend API:
https://chaiforms-t269.onrender.com

## ✨ Features

- User Authentication
- Create custom forms
- Dynamic form fields
- Email and Text input fields
- Shareable form links
- Collect responses
- Form dashboard
- tRPC based API

## 🛠️ Tech Stack

- Next.js
- TypeScript
- tRPC
- Express.js
- PostgreSQL
- Drizzle ORM
- Tailwind CSS
- Turborepo
- pnpm

## 📂 Project Structure
apps/
├── web # Frontend
└── api # Backend

packages/
├── database
├── trpc
├── logger
└── typescript-config


## 🚀 Getting Started

## Install dependencies:

pnpm install

## Run development:

pnpm dev

## Build project:

pnpm build
